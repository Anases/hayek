Hayek v3.0

Hayek is a lightweight HTTP client wrapper around the native fetch API. It handles JSON parsing automatically, throws on HTTP errors, and provides timeout support out of the box. The library weighs approximately 1.2kb when gzipped and has zero dependencies.

Installation #

Hayek works in any environment with fetch support: modern browsers, Node.js 18+, Deno, and Bun. You can include it directly via CDN or copy the source file into your project.

ES Module 
import { nanoGet, nanoPost } from 'https://cdn.jsdelivr.net/gh/anases/hayek@main/hayek.js';
HTML 
<script src="https://cdn.jsdelivr.net/gh/anases/hayek@main/hayek.js"></script>

Quick Start #

Here is a basic example showing how to make a GET request and handle the response.

TypeScript 
import { nanoGet, nanoPost } from 'hayek';

async function getUser(id: number) {
    try {
        const user = await nanoGet(`/api/users/${id}`);
        console.log(user.name);
    } catch (error) {
        console.error('Failed to fetch user:', error.message);
    }
}

async function createUser(data: object) {
    const user = await nanoPost('/api/users', {
        body: data,
        timeout: 5000
    });
    return user;
}

Preventing Race Conditions #

When users type quickly in a search box, multiple requests fire. Without cancellation, old responses can overwrite new ones. Use AbortController to cancel pending requests.

Search with Cancellation 
let controller = null;

async function search(query) {
    if (controller) controller.abort();
    controller = new AbortController();
    
    try {
        const results = await nanoGet(`/search?q=${query}`, {
            signal: controller.signal
        });
        displayResults(results);
    } catch (error) {
        if (!error.isAborted) {
            showError(error);
        }
    }
}

React Hook #

A custom hook that handles loading states, errors, and cleanup automatically.

useHayek Hook 
import { useState, useEffect } from 'react';
import { nanoGet } from 'hayek';

export function useHayek(url) {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(false);
    const [error, setError] = useState(null);

    useEffect(() => {
        if (!url) return;
        
        const controller = new AbortController();
        setLoading(true);
        
        nanoGet(url, { signal: controller.signal })
            .then(setData)
            .catch(err => {
                if (!err.isAborted) setError(err);
            })
            .finally(() => setLoading(false));
        
        return () => controller.abort();
    }, [url]);

    return { data, loading, error };
}

Security Notes #

Keep these points in mind when using any HTTP client in production:

  • CSP headers - Set Content-Security-Policy to restrict where requests can go
  • CORS - Browser security blocks cross-origin requests without proper headers
  • Auth tokens - Never store tokens in localStorage; use httpOnly cookies
  • Input validation - Sanitize user input before including in URLs
  • Error messages - Do not expose server error details to users
